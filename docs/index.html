Invoice Check Agents: evaluation results

A LangGraph multi-agent system checks supplier invoices against purchase orders, deliveries and contract prices, and is compared with one big model call that sees the same evidence. Both run on a free local model.

All suppliers, invoices, orders and contracts are SIMULATED
